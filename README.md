# DATA-STRUCTURE
🐍A data structure is a way of organizing and storing data in a computer so that it can be accessed and modified efficiently. It defines the relationship between the data and the operations that can be performed on it.
✅ List
Ordered, mutable, and allows duplicates
my_list = [1, 2, 3, "apple"]

✅ Tuple
Ordered, immutable, and allows duplicates
my_tuple = (1, 2, 3)
